## **`Material de Apoio`**

## O que é SO?

Controla o hardware da máquina e permite a execução de programas
### Kernel
O kernel funciona com uma ponte entre o Hardware e o Software, sendo peça central do Sistema Operacional
### Processo
O processo é como é chamado o programa que está em execução no momento
### Thread
Thread é uma técnologia que permite o uso de programas em segundo plano
## Unix
Unix é um sistema operacional multitarefa e multiusuário criado no final dos anos 1960
### Características
Multitarefa: permite executar vários programas ao mesmo tempo
Multiusuário: permite que várias pessoas usem o mesmo computador ao mesmo tempo
Portabilidade: pode rodar em diferentes tipos de computadores e hardware
Estrutura modular: é dividido em camadas
## Debian
Debian é um sistema operacional de código aberto baseado no Kernel Linux, ele é muito conhecido como “Sistema Operacional Universal” devido sua alta estabilidade, segurança e versatibilidade
### Características
Versão atual: versão estável mais recente é o Debian 13(Trixie), lançado em 2025 e atualizado continuamente (versão 13.7 em setembro de 2026)
Gerenciador de pacotes: Usa o ultilitario APT para gerenciar mais de 70.000 pacotes de software pré-compilados
Foca em estabilidade: prioriza pacotes maduros e testados em versão stable, sendo ideais para servidores de missão critíca e computadores pessoais que exigem confiabilidade
Suporte a hardware: inclui suporte nativo a firmwares proprientários no instalador padrão, facilitando reconhecimentos de placa de vídeos, WI-FI e bluetooth
## Ubuntu
O Ubuntu é um sistema operacional livre baseado em Linux
### Pricipais edições
Desktop: Para uso pessoal, criadores, estudantes e jogos em PCs e Laptops
Server: Para gerenciar dados, redes e infrestruturas de nuvem
Ubuntu PRO: um serviço com suporte estendido de segurança que pode chegar a até 15 anos
## Fedora linux
O Fedora Linux é um sistema operacional de código aberto patrocinado pela Red Hat, conhecido por trazer inovações técnilogias e software livres recentes
### Principais Edições
Fedora workstation: foco em computadores de uso pessoal e desenvolvedores, utilizando o ambiente gráfico GNOME
Fedora KDE Plasma Desktop: Edição alternativa com a interface KDE Plasma altamente personalizável
Fedora Server / Cloud / IoT: versões voltadas para servidores e ambiente em nuvem

## Sistema de Arquivos
Forma de organização de dados em um mídia de aramanezamento, como um HD

Há vários tipos de sistemas de arquivos, de acordo com o SO ou mídia como:

Windows: FATs, NTFS, exFAT, Explorador de arquivos

Linux: ext3, ext4m, btrfs, Diretório
## Diferença entre Cli e Gui
 ### Cli (Interface por linha de comando)
Você digita instruções em uma terminal e o sistema executa extamente o que pedido
### Gui (Interface gráfica do usuário)
Você clica com um cursor em icones e botões para executar comados 
## Virtualização
Virtualização é como chamamos a criação de "mini máquinas" dentro do computador
